# Credit Risk Scoring & Portfolio Monitoring

## About the Project
This project is based on loan risk analysis where the main goal was to identify high-risk customers and monitor overall loan portfolio exposure.

Using Python and Machine Learning, I predicted the probability of customer default and divided customers into Low, Medium, and High-risk categories. The processed data was then visualized in Power BI through an interactive dashboard.

---

## Tools & Technologies Used
- Python
- Pandas
- Scikit-learn
- Power BI
- DAX
- Excel

---

## What I Did
- Cleaned and prepared loan data using Python
- Applied Random Forest Classifier for risk prediction
- Calculated customer risk probability
- Created risk bands based on prediction scores
- Built an interactive Power BI dashboard for analysis

---

## Dashboard Features
- Total Customers KPI
- Risk Rate KPI
- High Risk Exposure KPI
- Risk Band vs Loan Amount chart
- Credit Score vs Risk Probability scatter plot
- High-risk customers table
